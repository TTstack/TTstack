TTstack — Lightweight Private Cloud

A tiny private cloud for developers and small teams. Create temporary VMs and containers on hosts you own, reach them over SSH or published ports, and stop, restart or delete them reliably.

Small by design

  • One controller, no extra infrastructure. No message queue and no database server are required; the controller and each agent keep their state in SQLite.
  • A single Rust workspace. tt for the command line, tt-ctl as the controller, tt-agent per host, and shared models, engines, storage and networking behind them.
  • Linux x86_64 hosts. QEMU/KVM, Firecracker and Docker/Podman are the supported engines; the host agent requires Linux.
  • Lifecycle before convenience. Creation is persisted before it executes, so an interrupted request can be inspected instead of blindly retried, and deletion that did not finish stays visible.

Supported scope, defaults and recovery semantics live in compatibility and the API reference, not on this page.
